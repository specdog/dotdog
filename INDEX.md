# spec — INDEX

Spec genome templates. Every file answers one question about the project-as-person.

Based on the reference implementation at [logohere/cryptchat specs/](https://github.com/logohere/cryptchat/tree/main/specs) — proven at ETHGlobal NYC 2026.

## Reading Paths

### First time here
```
README.md → spec-template.md → SPEC-template.md
```

### Setting up a new project
```
INDEX.md → spec-template.md → constitution-template.md → SPEC-template.md → data-model-template.md
```

### Setting up AI agents for a project
```
INDEX.md → spec-template.md → tasks/AGENTS-template.md → SPEC-template.md → data-model-template.md
```
